# Enna's Store

## 1. Nom du projet

**Nom du projet :** Enna's Store

---

# 2. Présentation du projet

Enna's Store est une mini boutique en ligne développée avec React. Elle permet aux utilisateurs de consulter un catalogue de produits, d'afficher les détails d'un article et de gérer un panier d'achat. Cette application s'adresse aux utilisateurs souhaitant découvrir une expérience d'achat simple et fluide. Son objectif principal est de mettre en pratique le développement d'une interface e-commerce moderne avec React.

---

# 3. Problématique

Le problème identifié est que les utilisateurs ont besoin d'une interface simple pour consulter des produits et gérer un panier d'achat.

La solution proposée permet de parcourir un catalogue de produits, consulter leurs informations détaillées et ajouter les articles au panier de manière intuitive.

---

# 4. Fonctionnalités principales

- Consulter la liste des produits.
- Afficher les détails d'un produit.
- Ajouter un produit au panier.
- Modifier la quantité des produits dans le panier.
- Naviguer entre les différentes pages grâce à React Router.
- Gérer dynamiquement les données avec React Hooks.

# 6. Installation et lancement

## 6.1 Prérequis

- Node.js

- Git

---

Aucune variable d'environnement n'est nécessaire pour ce projet.

# 9. Difficultés rencontrées

## Difficulté 1

### Problème rencontré

La gestion de l'état du panier entre plusieurs composants.

### Recherches / Tests

J'ai étudié le fonctionnement des Hooks React et testé plusieurs méthodes de gestion de l'état.

### Solution

J'ai centralisé l'état du panier dans le composant principal et transmis les données aux composants enfants via les props.

### Ce que j'ai appris

J'ai appris à mieux gérer le state et la communication entre composants React.

### Texte final

J'ai rencontré le problème suivant : la synchronisation des données du panier entre plusieurs composants.

Pour comprendre l'origine du problème, j'ai étudié le fonctionnement des Hooks React et réalisé plusieurs tests.

J'ai résolu le problème en centralisant le state dans le composant principal.

Cette difficulté m'a permis d'apprendre à mieux organiser une application React.

---

## Difficulté 2

### Problème rencontré

La mise en place de la navigation entre les différentes pages.

### Recherches / Tests

J'ai consulté la documentation officielle de React Router et réalisé plusieurs essais.

### Solution

J'ai utilisé React Router pour créer les différentes routes de l'application.

### Ce que j'ai appris

J'ai appris à structurer une application React composée de plusieurs pages.
