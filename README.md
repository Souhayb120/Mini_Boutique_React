Enna's Store est une application web e-commerce responsive développée avec React. Elle permet aux utilisateurs de parcourir les produits, consulter leurs détails, ajouter des articles au panier et gérer leurs achats grâce à une interface moderne, intuitive et conviviale. Ce projet met en avant les concepts fondamentaux de React, notamment les composants, le routage, la gestion d'état et les formulaires.
