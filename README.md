
Enna's Store est une application web e-commerce responsive développée avec **React**. Elle permet aux utilisateurs de parcourir une liste de produits, consulter les détails de chaque article, ajouter des produits au panier et gérer leurs achats à travers une interface moderne, intuitive et facile à utiliser. Ce projet met en valeur les compétences en développement Front-End, notamment l'utilisation de React, React Router, la gestion de l'état, les formulaires et la création de composants réutilisables.

Fonctionnalités :

* ✅ Affichage de la liste des produits
* ✅ Consultation des détails d'un produit
* ✅ Ajout des produits au panier
* ✅ Gestion du panier (quantité et suppression)
* ✅ Navigation avec React Router
* ✅ Interface responsive et conviviale
* ✅ Formulaire d'ajout de produit avec validation
* ✅ Composants réutilisables et architecture organisée
